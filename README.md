## 🚀 Nossa Visão

O **FéConecta** não é apenas uma rede social; é o epicentro digital da comunidade cristã. Projetado para conectar pessoas, igrejas e propósitos, o aplicativo integra ferramentas de alto engajamento, como Inteligência Artificial avançada para estudos teológicos, um diário espiritual blindado e interações sociais em tempo real, proporcionando um ambiente seguro e focado no crescimento.

---

## ✨ Principais Diferenciais

O FéConecta se destaca pela sua arquitetura moderna e funcionalidades desenhadas para retenção e engajamento:

### 🧠 Inteligência Artificial Teológica Integrada
Motor de Análise Bíblica alimentado pelo modelo **Google Gemini 2.5 Flash**. Capaz de realizar exegese profunda, sugerir planos de leitura e auxiliar em dúvidas teológicas complexas, tudo de forma nativa e sem fricção na interface do usuário.

### 📊 Dashboard e Monitoramento em Tempo Real
Para administradores e igrejas, o sistema oferece controle total sem depender de mocks estáticos. Sensores de saúde live para streaming de áudio (LiveKit), controle de receita PIX e monitoramento de engajamento de Stories e publicações nas últimas 24h.

### 📖 Engine Persistente de Diário Espiritual
Um fluxo atômico de anotações ("Meu Diário"). A interface colapsável garante a melhor experiência de usuário para estudos longos. O sistema conta com um deep-tracking de auditoria para proteger os dados e pensamentos mais íntimos dos usuários.

### 🎧 Streaming e Mídia Avançada
- **Salas de Áudio (War Rooms):** Comunicação de voz em tempo real viabilizada pelo *LiveKit*, permitindo células e grupos de oração virtuais.
- **FéMusic:** Player nativo que processa e reproduz louvores integrando-se perfeitamente à experiência de navegação (sem interromper a música ao trocar de tela).

## 🏗️ Arquitetura e Engenharia (Stack)

Desenvolvido para escalar e suportar alta concorrência:
- **Core & Frontend:** Next.js 15+ (App Router), React 19, TypeScript
- **Backend & Auth:** Supabase (PostgreSQL nativo com Row Level Security)
- **UI/UX:** Tailwind CSS 4, Radix UI, Framer Motion
- **IA Generativa:** Vertex AI / Google Generative AI
- **Infraestrutura:** Vercel (Edge Functions) e WebSockets para tempo real

---

## 🔮 Expansão do Ecossistema (Roadmap)

A arquitetura paralela está pronta para se expandir em novos horizontes lucrativos e de alta retenção:

- 💑 **FéNamoro:** O "Tinder Cristão". Uma rede conjugada com o FéConecta, compartilhando a mesma base de usuários (arquitetura semelhante à integração Instagram ↔ Threads).
- 💬 **FéChat (WhatsCristão):** Aplicativo de mensageria instantânea dedicado à comunicação direta e segura, atuando como o comunicador oficial do ecossistema.
- 📹 **Motor Nativo de Mídia:** Extração e processamento dinâmico de vídeos (robôs escravos paralelos) para substituir iframes, habilitando autoplay e performance absurda como no TikTok e Reels.

## 📦 Inicialização do Projeto

Para desenvolvedores e auditores técnicos:

```bash
# 1. Clone o repositório
git clone https://github.com/vinnicirne/newfeconecta.git

# 2. Instale as dependências
npm install

# 3. Configure as variáveis de ambiente (.env.local)
# Requer: SUPABASE_URL, SUPABASE_ANON_KEY e GEMINI_API_KEY

# 4. Inicie o servidor em ambiente de desenvolvimento
npm run dev
```
